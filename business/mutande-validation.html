The problem
Root pain

Developers running multiple AI tools — Cursor, Claude, ChatGPT — are manually copying context between them dozens of times a day. They are the courier. There is no native way for their agents to talk to each other.

How it shows up

Copy-paste between chat windows. Emailing themselves. Slack messages to no one. Re-explaining the same context in every new session. Handoffs that silently drop information.

Ideal customer profile
Who
Solo dev or 2–5 person founding team. Founder-engineer or CTO. Decides in days, pays from a card.
Setup
Running 2+ AI tools simultaneously. Mac or Windows. Ships fast, context-switches constantly.
Stack
Model-agnostic. Cursor + Claude + ChatGPT in the same week. No framework loyalty.
Trigger moment
Just lost critical context switching between tools. Or re-explained the same brief for the 5th time this week.

What's working

Working product in alpha — not a deck, not a prototype. MCP server live, Mac + Windows app shipping.

No clear category winner — "agent address layer" is unnamed territory. First to define it owns it.

E2E encryption on desktop — real differentiator. The hub never reads your content. Competitors can't say that.

Model-agnostic — works across Cursor, Claude, ChatGPT. Not locked to one ecosystem.

Pain is live and searchable — devs are complaining about manual agent handoffs on X, Discord, and GitHub right now.

What needs pressure-testing

Desktop-first limits reach — browser agents (Claude.ai, ChatGPT web) get a weaker, non-E2E path via hosted MCP. Many devs live in the browser.

Network effects needed — addresses only matter if teammates are on mutande too. Cold start problem is real.

LangSmith expanding fast — already positioning around EU AI Act compliance and agent ops. Watch their roadmap closely.

Monetization not locked — per-seat pricing works for human orgs, but agent-native pricing (per address? per thread volume?) may fit better long-term.

Go-to-market — first 10 teams
01

Find the pain in public. Search X, Anthropic Discord, Cursor community, and Claude Code GitHub issues for "copy paste between" / "re-explaining to" / "lost context switching". These are your first DMs.

02

Seed with solo power users first. One-person installs have no cold-start problem. They have multiple agents already. Get them addicted before targeting teams.

03

Ship a frictionless onboarding moment. The first handoff — agent A sends to agent B without the developer touching it — needs to feel like magic. That's your word-of-mouth moment.

04

Build in public. Post the problem, not just the product. "I was copy-pasting between Cursor and Claude 20 times a day" is a post that finds your ICP for free.

05

Teams come second. Solo users invite cofounders. Cofounders invite contractors. That's your land-and-expand. Don't sell teams cold — let solo users pull them in.
