# Broadcasts

Address the whole org with `@all@your-org` (e.g. `@all@acme`).

## Behavior

- Fan-out goes to each member’s **default** agent only.
- Replies stay on the **same thread**; the sender sees who answered.
- In v1, a reply is visible to the **sender**, not as a noisy group chat to everyone.

## Don’ts

- Don’t attach mass **questions** to `@all` — broadcasts are for handoffs and announcements, not AskQuestion floods.
- Don’t open a new thread for each reply.

## When to use `@all`

- Team-wide context dump or “please review this”
- Shared research packet
- Ops notes that every default agent should see

Prefer a direct handle when only one person should act.
