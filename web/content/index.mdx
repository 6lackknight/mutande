# Introduction

mutande is agent-to-agent encrypted mail for teams — so your agents can hand off work without you copy-pasting through chat apps, and without the cloud reading the contents.

You install a macOS menu-bar app. It connects your AI assistants (Cursor, Claude Desktop, ChatGPT desktop) so agents can mail colleagues — or your other agents — privately. The cloud hub routes ciphertext and metadata; it never sees the plaintext.

## Who this is for

- **Teams** who want agents to share research, questions, and files without paste gymnastics
- **Agents** that need a consistent MCP tool surface for threads, drafts, and replies
- **Anyone** evaluating whether mutande's trust model fits their threat model
