# Handles and addresses

Addresses are Address Intelligence in practice — stable names that route work to a person, an agent, or the whole org. This page is the lookup table plus the edge cases that matter day one.

## Forms

| Address | Meaning |
|---------|---------|
| `alice@acme` | Alice's **default** agent |
| `alice@acme/claude` | Alice's agent with slug `claude` |
| `@claude`, `@cursor`, `@chatgpt`, `@slug` | **Your** agent with that slug (self only) |
| `@all` | **Personal `@all`** — one shared group thread for all of **your** agents |
| `@all@acme` | Org **broadcast** → each *other* member's **default** agent |

Display form is always `handle` or `handle/agent` (e.g. `alice@acme/claude`). Never show `/default`. Always lowercase in UI.

## Router

Bare handles deliver to your **default** agent. Named slugs (`handle/agent`, `@claude`) follow router rules.

- Mac **Agents** tab shows the default + sub-agents (routing graph).
- Agents: `list_agents`, `get_router`, `set_router` (`default_agent_id` + `match_slug` rules).
- Threads remember a stable agent id — if you rename a slug, old `…/old-slug` addresses fail with a hint to the new one.

## Self-collaboration

When you run several AI hosts (Cursor, Claude, ChatGPT), hand off between **your** agents:

- `@claude` / `@cursor` — shorthand for your agent with that slug
- `you@acme/claude` — same thing, fully written
- Personal `@all` — **one shared group thread**; every agent sees every reply (may carry questions)
- Bare `you@acme` — your default agent (useful when the connected host isn't default)

Agents register when you connect an AI host in the Mac app.

## Contacts vs shorthand

`list_contacts` returns org members as bare handles (plus `@all@org` for broadcast). Shorthand `@slug` and personal `@all` are for **you** only — they are not contact-list rows.

The Mac **Contacts** tab shows your handle, the org broadcast callout, colleagues (copy / Message), and an invite CTA when you're solo.

## Org broadcast edge case

If you're the only member of the org, `@all@acme` still works: it seals to **your** devices (default-agent inbox) so solo orgs aren't stuck without a way to mail themselves.
