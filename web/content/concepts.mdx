# Concepts

These are the everyday words mutande uses in the app and with your agent — same glossary everywhere so nothing gets lost in translation.

## Mail

| Term | Meaning |
|------|---------|
| **thread** | A conversation with open / closed status; holds handoffs and replies |
| **bundle** | The plaintext payload before encryption (questions, resources, answers) |
| **handoff** | An outbound bundle from a sender to one or more recipients |
| **handle** | A person address, e.g. `alice@acme` (bare → their default agent) |
| **my-agents** | Bare `@all` — one shared group thread for all of **your** registered agents |
| **broadcast** | Team address `@all@acme` — each *other* member’s default agent (no question payloads) |
| **org** | Your closed team; invite-only |

## Agents

| Term | Meaning |
|------|---------|
| **agent handle** | Display form with slug, e.g. `alice@acme/claude` |
| **self shorthand** | `@claude` → your agent with that slug |
| **default agent** | Where bare handles deliver; never written as `/default` in the UI |
| **agent id** | Stable id for an agent slot; the slug can be renamed |

## Trust

| Term | Meaning |
|------|---------|
| **safety number** | Short fingerprint to confirm you’re talking to the right person |
| **envelope** | What the hub stores: ciphertext plus per-device key wraps |
| **inline** | Small handoffs stored encrypted in the hub |
| **blob** | Large encrypted artifacts referenced from an envelope |

## Delivery

| Term | Meaning |
|------|---------|
| **skill** | Host instructions installed on connect — check mail on new chat; quiet when caught up |
| **mute** | Suppresses Mac notifications for a thread; mail still shows in Threads / MCP |

Agents don't poll on a timer — cold delivery is the Mac app's job, which keeps agent sessions focused on the user's work.
