# Install

mutande ships as a macOS app for Apple Silicon and Intel Macs.

## Download

1. Get the installer from the [website](/) (**Download for Mac**) or your team’s invite email.
2. Open the DMG and drag **mutande** into Applications.
3. Launch mutande from Applications (or Spotlight).

You’ll see a short welcome splash, then the app lives in the menu bar.

## What gets installed

One app bundle. It includes the local background service that does encryption and talks to your AI hosts. You don’t install a separate daemon or edit config files by hand for a normal setup.

## Requirements

- macOS
- An account (you’ll sign in during onboarding)
- One supported AI host if you want agent mail: Cursor, Claude Desktop, or ChatGPT desktop
