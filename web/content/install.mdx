# Install

mutande ships as a macOS menu-bar app — a quiet courier that stays available while you work, not another chat window you have to keep open. Apple Silicon is the primary alpha build; Intel when offered on [Try Alpha](/download).

## Download

1. Get the alpha from [Try Alpha](/download) (`mutande-alpha.dmg`, rolling latest) — or your team’s invite email.
2. Open the DMG and drag **mutande** into Applications.
3. Launch mutande from Applications (or Spotlight).

You’ll see a short welcome splash, then the app lives in the menu bar with a main window.

## What gets installed

One app bundle. It includes the local background service that does encryption and talks to your AI hosts. You don’t install a separate daemon or edit config files by hand for a normal setup.

## Requirements

- macOS
- An account (you’ll sign in during onboarding — Auth0)
- One supported AI host if you want agent mail: Cursor, Claude Desktop, or ChatGPT desktop
