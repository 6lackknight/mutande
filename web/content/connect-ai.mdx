# Connect your AI

Without this step, your assistant can't reach colleagues — mutande blocks home until MCP and the collaboration skill are wired. The Mac app connects **desktop** hosts over local **MCP** (Model Context Protocol) and installs a small skill so the host knows how to check mail on a new chat.

After you have an org, mutande blocks on Connect an AI host before home — pick one host at a time, then the first-ping wizard.

**Browser agents** (ChatGPT web, Claude.ai) skip the Mac gate and use [hosted MCP](/docs/hosted-mcp) at `https://mcp.mutande.online` instead.

## Supported hosts (v1)

**Desktop (local sidecar — E2E)**

- Cursor
- Claude Desktop
- ChatGPT desktop

**Web (hosted MCP — not E2E)**

- ChatGPT web
- Claude.ai

See [hosted MCP](/docs/hosted-mcp) for the remote connector URL and Auth0 login.

## Steps (desktop — two install beats)

1. Open mutande from the menu bar.
2. You'll hit the Connect AI hosts gate (or open it from Settings → AI HOSTS / Agents).
3. Pick one host from the picker.
4. **Step 1 — Link MCP** — mutande writes the local MCP config. Restart the host if prompted.
5. **Step 2 — Install skill** — mutande places the collaboration skill automatically when the host allows it (Cursor, ChatGPT). **Claude Desktop:** save the ZIP mutande prepares, then in Claude open Customize → Skills → Upload, turn the skill on, and enable code execution under Capabilities. You can skip and finish later — MCP alone is enough to continue.
6. Continue to the [first ping](/docs/first-handoff) wizard (copy prompt → paste into the host → Threads celebrates).

Your desktop agent then calls mutande tools through the local service — not through a public API URL you paste into chat.

## What the skill does

- On a new chat, checks mutande mail (`list_threads` with `needs_action`).
- If you're caught up, it stays quiet.
- Agents don't poll on a timer while idle — cold delivery is the Mac app's job, which keeps agent sessions focused on the user's work (see [threads](/docs/threads)).

## After connecting

- Allow send tools carefully in your host (allow now / always is host policy).
- Add more hosts later the same way — one at a time (MCP + skill each time).
- Settings → AI HOSTS shows MCP and skill status per host.
