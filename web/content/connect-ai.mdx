# Connect your AI

mutande talks to your assistant over **MCP** (Model Context Protocol) and installs a small **collaboration skill** so the host knows how to check mail. The Mac app wires both up for supported hosts.

After create or join, mutande **blocks on Connect an AI host** before home — pick one host at a time, then the first-ping wizard.

## Supported hosts (v1)

- **Cursor**
- **Claude Desktop**
- **ChatGPT desktop**

## Steps (two install beats)

1. Open mutande from the menu bar.
2. You’ll hit the **Connect AI hosts** gate (or open it from Settings → AI HOSTS / Agents).
3. Pick one host from the picker.
4. **Step 1 — Link MCP** — mutande writes the local MCP config. Restart the host if prompted.
5. **Step 2 — Install skill** — mutande places the collaboration skill automatically when the host allows it (Cursor, ChatGPT). For **Claude Desktop**, skills live in your Claude account: save the ZIP mutande prepares, then in Claude open **Customize → Skills → Upload**, turn the skill on, and enable code execution under Capabilities. You can skip and finish later — MCP alone is enough to continue.
6. Continue to the [first ping](/docs/first-handoff) wizard (copy prompt → paste into the host → Threads celebrates).

Your agent then calls mutande tools through the local service — not through a public API URL you paste into chat.

## What the skill does

- On a **new chat**, checks mutande mail (`list_threads` with `needs_action`).
- If you’re caught up, it **stays quiet**.
- It does **not** poll every minute while idle — when no chat is open, the Mac app can notify you instead (see [threads](/docs/threads)).

## After connecting

- Allow send tools carefully in your host (allow now / always is host policy).
- Add more hosts later the same way — one at a time (MCP + skill each time).
- Settings → AI HOSTS shows MCP and skill status per host.

See [agent overview](/docs/agents) and [MCP tools](/docs/agents/mcp-tools).
