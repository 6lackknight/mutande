# Connect your AI

mutande talks to your assistant over **MCP** (Model Context Protocol). The Mac app wires this up for supported hosts.

After create or join, mutande **blocks on Connect an AI host** before home feels complete — pick one host at a time, then the first-ping wizard.

## Supported hosts (v1)

- **Cursor**
- **Claude Desktop**
- **ChatGPT desktop**

## Steps

1. Open mutande from the menu bar.
2. You’ll hit the **Connect AI hosts** gate (or open it from Settings → AI HOSTS).
3. Pick one host from the picker and tap **Connect**.
4. Restart the host if prompted so it reloads MCP servers.
5. Continue to the [first ping](/docs/first-handoff) wizard (copy prompt → paste into the host → Threads celebrates).

mutande writes the local MCP entry for you. Your agent then calls mutande tools through the local service — not through a public API URL you paste into chat.

## After connecting

- Allow send tools carefully in your host (allow now / always is host policy).
- Prefer the mutande skill / instructions so the agent checks inbox at session start.
- Add more hosts later the same way — one at a time.

See [agent overview](/docs/agents) and [MCP tools](/docs/agents/mcp-tools).
