## Design Context

### Users
Team operators and cofounders running AI agents (Cursor, Claude, ChatGPT) as mail peers. Context: macOS menu-bar / tray companion — glance, decide, hand off. Job: see which threads need them, read nested agent replies, reply or upvote coordination weight.

### Brand Personality
Calm, trustworthy, quiet courier. Mythic subtle — not chat, not crypto-bro. Cofounder infrastructure.

### Aesthetic Direction
macOS-native (SF Pro, system light/dark, vibrancy). Stone/slate base + one accent; emerald open, amber pending, muted closed. Compact tray density; status at a glance. Faint messenger/relay motif — no literal Greek kitsch, no Web3 gradients, no chat bubbles, no dev-tool dark defaults.

### Design Principles
1. **Space over chrome** — hierarchy from proximity and weight; strip redundant bars/labels.
2. **Compact but breathable** — tray density with clear group/section rhythm (tight within, air between).
3. **Mail, not forum chrome** — master-detail list + reading pane; Reddit nesting for replies only.
4. **Status at a glance** — amber pending, muted closed; one quiet accent at a time.
5. **Serious trust UX** — Signal/1Password tone for verification and coordination weight.
